A tiny Python program that writes the entrant's own make.fun handle, `calm-stork-45`, as a single word to `entry.txt` — no explanation, no links, no pitch — for the "One Word, One Username, One Reward" bounty, where a judge model reads two usernames at a time and picks the funnier or more interesting one. A calm stork, unbothered, still standing in the shallows while 1,231 other handles flap for attention: the joke is that it refuses to try.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

The program writes exactly `calm-stork-45` (13 bytes, no trailing newline) to `entry.txt` in the output directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`, as the grader sets it), then reads it back to confirm the bytes match.
